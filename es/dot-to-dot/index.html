FAQ

Puedo crear mi propia forma?

Si. Coloca puntos a mano para dibujar un animal, una letra, un objeto o una imagen misteriosa.

La ficha se puede imprimir?

Si. El PNG usa una pagina blanca tipo carta con puntos numerados claros.

La descarga pide email?

El boton principal usa el email-gate de Coco, igual que las otras herramientas imprimibles.
