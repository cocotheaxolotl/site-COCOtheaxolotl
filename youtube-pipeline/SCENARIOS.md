# Scénarios shorts — Coco the Axolotl

12 scénarios d'acquisition prêts à tourner. Chaque scénario = 30-45s, format 9:16, cible parents 25-45.

Format : Hook overlay 1 (0-3s) → Hook overlay 2 (3-6s) → narration scène par scène → CTA.

Tous les chiffres et anecdotes sont **éditables** : remplace par tes propres chiffres/anecdotes vraies.

## Comment utiliser

1. **Choisis 3-4 scénarios à tester** (mix des 3 livres + mix angles : pain / vulnérabilité / autorité)
2. Pour chaque scénario validé, je le passe en JSON dans `output/scripts/` au format pipeline
3. `python src/run.py <slug> en <angle>` génère le short complet

**Recommandation premier test** : Scenario 1 (pain validation universelle) + Scenario 7 (confession émotionnelle) + Scenario 11 (screen time angle = très partagé).
