política de Privacidade

ENFRESPT

1. Introdução

Esta Política de Privacidade explica como Coco the Axolotl coleta, usa e protege dados pessoais quando você visita ou interage com o site cocotheaxolotl.org. Estamos empenhados em proteger a sua privacidade e tratar os dados de forma transparente e segura.

2. Dados que coletamos

Poderemos recolher os seguintes dados pessoais:

  • Nome
  • Endereço de email

Os dados pessoais são recolhidos apenas quando os utilizadores os fornecem voluntariamente, por exemplo, quando solicitam conteúdos descarregáveis ​​ou subscrevem atualizações.

3. Uso de dados

Os dados pessoais recolhidos são utilizados exclusivamente para as seguintes finalidades:

  • Envio de jogos gratuitos para impressão ou conteúdo educacional
  • Fornece atualizações relacionadas aos livros, jogos ou atividades de Coco, o Axolotl

4. Compartilhamento de dados

Seus dados nunca são vendidos, alugados ou compartilhados com terceiros.

5. Retenção de dados

Os dados pessoais são conservados apenas durante o tempo necessário ao cumprimento das finalidades acima descritas ou até que solicite a sua eliminação.

6. Segurança de dados

Implementamos medidas técnicas e organizacionais adequadas para proteger os dados pessoais contra acesso, alteração, divulgação ou destruição não autorizados.

7. Seus direitos

De acordo com os regulamentos de proteção de dados aplicáveis, incluindo o Regulamento Geral de Proteção de Dados (RGPD), você tem o direito de:

  • Acesse seus dados pessoais
  • Corrija seus dados pessoais
  • Solicitar a eliminação dos seus dados pessoais

Para exercer estes direitos, por favor contacte: coco@cocotheaxolotl.org

8. Biscoitos

Este site não utiliza cookies de rastreamento ou publicidade. Apenas podem ser utilizados cookies técnicos estritamente necessários para garantir o correto funcionamento do site.

9. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada a qualquer momento. Quaisquer alterações serão publicadas nesta página com uma data de revisão atualizada.

10. Contato

Se tiver alguma dúvida sobre esta Política de Privacidade ou sobre o tratamento dos seus dados pessoais, pode contactar-nos em: coco@cocotheaxolotl.org
