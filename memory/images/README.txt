MEMORY GAME IMAGES FOLDER
=========================

Add your images here for the Memory card matching game.

Accepted formats: .jpg, .jpeg, .png, .webp
Recommended size: 400x400 px (square) or any square format.
Non-square images will be cropped automatically (object-fit: cover).

Naming: use simple names without spaces, e.g.:
  coco-beach.jpg
  coco-dragon.jpg
  coco-unicorn.jpg

To add images to the game, open memory/index.html and add the
filenames to the ALL_IMAGES array near the top of the <script> section.

The game needs at least 15 images to support Hard mode (15 pairs).
